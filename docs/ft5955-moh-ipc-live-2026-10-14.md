The user's terminal output confirms:

Do not upload the user's fingerprint images, private MOH DLL or template bytes.

## Next blocking question: template portability

A libfprint driver must return an `FpPrint` that can be serialised and later restored. The current MOH adapter holds the vendor's template bytes within its isolated process, discarding them at shutdown. It would be incorrect for the libfprint driver to report successful persistent enrolment while only maintaining RAM-only mock records.

A separate **v0.4 experimental template restart probe** has been packaged for local testing. It creates a fresh sandbox using a temporary copy of the existing audited engine runner; it neither modifies the working MOH feature worktree nor replaces the original runner. It aims to:

1. Enrol one finger with 12 accepted impressions.
2. Export only the temporary vendor template plus subfactor through local anonymous pipes into private process memory.
3. Close that engine sandbox, start a new isolated instance and import the same template.
4. Verify a new same-finger impression and test a different finger for no-match.

The new probe passed **synthetic** cross-process template export/import/verify tests locally. Its compatibility with the actual FocalTech Windows engine remains unverified pending an explicit on-device test. It writes no template or raw image files; it is a development diagnostic, not production storage.

## Integration requirements

Keep the existing GUI, two-finger identification tool, USB helper and MOH engine sandbox intact. The separate `libfprint-ft5955` worktree already handles discovery, open/close, a handshake and a one-time finger status read. Additional work is required for asynchronous bounded capture, cancellation, adapter process lifetime, serialisable `FpPrint` data, reopened-engine template import and real verification before testing any private `fprintd` instance. Do not enable desktop login or modify system PAM/fprintd until reliability, negative controls, persistent storage and recovery behaviour have been established.
