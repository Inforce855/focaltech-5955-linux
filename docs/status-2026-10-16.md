## Documentation convention

When each milestone is tested, update this status note and [roadmap](roadmap.md) with:
- **date**, **exact test command/version**, **observed result** (PASS/FAIL/PENDING);
- which component was tested (raw USB, local matching bridge, native libfprint, private fprintd, system fprintd);
- whether the test used real fingers or synthetic inputs;
- residual limitations and data/privacy risks.

Never publish RAW or PGM captures, templates, identity-labelled biometric results or proprietary vendor binaries.
